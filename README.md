📦 Projeto: Consulta de CEP com Java Swing
📖 Sobre o projeto

Este projeto foi desenvolvido durante o 3º semestre da disciplina de Programação Orientada a Objetos (POO).

O objetivo principal é integrar uma API de busca de CEP a uma aplicação desktop construída em Java, permitindo a consulta de endereços a partir de um CEP informado pelo usuário.

🎯 Objetivos
Aplicar conceitos fundamentais de Programação Orientada a Objetos
Trabalhar com consumo de APIs externas
Desenvolver uma interface gráfica simples utilizando Java Swing

🛠️ Tecnologias utilizadas
Java
Java Swing (interface gráfica)
API de consulta de CEP (ex: ViaCEP)

⚙️ Funcionalidades
Consulta de endereço a partir de um CEP
Lista histórico de busca do usuário
Exibição dos dados retornados pela API
Interface gráfica simples para interação com o usuário
🧠 Conceitos aplicados
Encapsulamento
Separação de responsabilidades
Consumo de API REST

📌 Observações
Este projeto tem caráter acadêmico e foi desenvolvido com foco no aprendizado dos conceitos base de POO e integração com serviços externos.

A interface foi construída utilizando recursos básicos do Java Swing, com apoio de ferramentas visuais para posicionamento dos componentes.
